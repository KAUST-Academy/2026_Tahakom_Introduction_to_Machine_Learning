\vspace{0.4em}
{\footnotesize \empr{Frame it as an analogy, not an identity.} The shared property
is \emph{offline optimization without distribution coverage} (same family, not
the same mechanism):
\begin{itemize}\itemsep0.1em\footnotesize
    \item \textbf{Offline RL:} the \emph{value function} extrapolates on
          out-of-distribution (OOD) \emph{actions}.
    \item \textbf{DPO:} the \emph{policy / implicit reward} is unconstrained on OOD
          \emph{responses}, because it never samples on-policy.
\end{itemize}}
\srcnote{\scriptsize Cf.\ Xu et al., \href{https://arxiv.org/abs/2404.10719}{Is DPO Superior to PPO for LLM Alignment?}, ICML 2024.}
